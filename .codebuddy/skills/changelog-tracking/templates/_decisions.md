# 决策素材（_decisions）

> 需求分析过程中每次"拍板确认"当场追加。与 `requirement-analysis` 技能的决策记录同源。
> 本文件是变更日志 `decision` 来源的原始素材。

```yaml
- time:     "YYYY-MM-DDThh:mm:ss+08:00"
  type:     decision
  summary:  "一句话变更点"
  detail:   "变更前 → 变更后"
  source:   "需求分析拍板"
  scope:    "F01 / 页面名 / 模块"
  decider:  "user / 角色名"
  evidence: "对话轮次 / 文档锚点"
```
