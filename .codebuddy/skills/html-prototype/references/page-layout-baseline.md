# 页面布局与样式基线

通用骨架与样式约定。**本基线只含结构与样式，数据一律占位符**；项目演示数据应放运行期产物，不写入本文件。

## 一、CSS 变量（主题集中管理）

```css
:root {
  --c-primary: #2f6fed;
  --c-primary-dark: #1f52bb;
  --c-text: #1f2329;
  --c-text-sub: #646a73;
  --c-border: #dee0e3;
  --c-bg: #f5f6f7;
  --c-surface: #ffffff;
  --c-success: #34c724;
  --c-warning: #ff8800;
  --c-danger: #f54a45;
  --radius: 6px;
  --space: 16px;
  --space-sm: 8px;
  --font: "PingFang SC", "Microsoft YaHei", sans-serif;
}
```

## 二、页面骨架

```
┌───────────────────────────────────────┐
│ 顶栏：Logo / 系统名 / 用户              │
├──────────┬────────────────────────────┤
│ 侧边导航 │ 页面标题 + 面包屑            │
│          ├────────────────────────────┤
│          │ 操作区（查询/按钮）          │
│          ├────────────────────────────┤
│          │ 内容区（表格/表单/详情）      │
│          ├────────────────────────────┤
│          │ 分页 / 底部操作              │
└──────────┴────────────────────────────┘
```

## 三、通用组件样式要点

| 组件 | 要点 |
|------|------|
| 表格 | 表头浅灰底、行悬停高亮、操作列右对齐、空数据占位行 |
| 表单 | 标签右对齐或上对齐统一；必填星号；错误态红边框+提示 |
| 按钮 | 主操作实底、次操作描边、危险操作红；禁用态降透明度 |
| 状态标签 | 圆角小标签，按语义取色（成功/警告/危险/中性） |
| 提示 | Toast 右上角 3s 自动消失；确认弹窗遮罩居中 |
| 分页 | 右下角，含总数与每页条数选择 |

## 四、状态呈现

| 状态 | 呈现 |
|------|------|
| 加载中 | 骨架屏或转圈 + 文案"加载中…" |
| 空数据 | 图标 + "暂无数据" + 可选主操作按钮 |
| 错误 | 图标 + 错误说明 + "重试"按钮 |
| 无权限 | 图标 + "暂无访问权限" + 返回入口 |

## 五、规范

- 间距统一用 `--space` 系列，禁止随意写死像素。
- 圆角统一 `--radius`。
- 主色仅用于主操作与强调，避免满屏高饱和。
- 所有页面复用同一骨架，保证跨页视觉一致。
