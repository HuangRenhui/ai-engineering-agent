## 字段说明

| 字段 | 含义 |
|------|------|
| 时间 | 变更发生时间（ISO 8601 含时区） |
| 版本 | 变更后的契约版本（`v0.1` → `v0.2`） |
| 变更项 | 具体到 `API-xx` / 字段 / 枚举值 / 错误码 |
| 原因 | 为何变更（业务调整 / 评审意见 / 缺陷修正） |
| 申请人 | 提出方（`user` / `/ai-dev-frontend` / `/ai-test-design` / `/ai-dev-backend`） |
| 影响范围 | 受影响的功能 `F`、接口 `API`、页面 `P`、用例 `TC` |
| 需重新对齐 | 前端 / 测试需重做的范围（未受影响写"无"） |
