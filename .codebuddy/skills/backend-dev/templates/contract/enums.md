## 4. 实现约定

- 后端一律用**枚举 / 常量**承载，禁止在业务代码中出现魔法值（数字或字符串硬编码）；
- 未知取值：出参不臆造新值，按 `<原值透出 / 归一为 UNKNOWN>` 处理，并在 `impl-report.md` 说明；
- 前端展示文案以本表"前端展示"列为准，前端不得自行改文案（改文案须经契约变更流程）；
- 可扩展枚举**新增值不视为破坏性变更**；删除或改语义必须 `version`+1 并通知前端 / 测试增量重做。
