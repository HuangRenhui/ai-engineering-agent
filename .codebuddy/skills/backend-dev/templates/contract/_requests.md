# 契约变更申请 · <项目名称>

> 由 `/ai-dev-frontend`、`/ai-test-design` 追加提交；**申请方不得直接修改契约文件**。
> 由 `/ai-dev-backend` 裁决：采纳 → 走契约变更五步（改契约 + `version`+1 + `status: changed` + `_change-log.md` + `changelog/`）；不采纳 → 填写裁决结论与理由。
> 未裁决项**不阻塞**申请方开发（申请方在自身报告登记偏差与临时适配方式后继续推进）。

## 字段说明

| 字段 | 含义 |
|------|------|
| 时间 | 提交时间（ISO 8601 含时区） |
| 申请人 | `/ai-dev-frontend` / `/ai-test-design` |
| 契约位置 | 精确到 `API-xx` + 字段 / 枚举值 / 错误码 / 表字段 |
| 期望变更 | 明确写成"由 X 改为 Y" |
| 理由 | 依据来源（PRD/AC、原型文案、权限矩阵、不可测问题），禁止"感觉更合理" |
| 影响范围 | 受影响 `F` / `P` / `TC`；申请方当前临时适配方式 |
| 裁决 | `adopt` / `reject` / `defer`（仅后端或用户填写） |
| 裁决结论 | 采纳后的版本号或驳回理由；`defer` 须写待定条件与 `owner` |
