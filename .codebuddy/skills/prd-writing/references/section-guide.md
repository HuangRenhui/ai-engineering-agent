# PRD 章节写作指南

逐章节说明"写什么、写到什么程度、如何自检"。

> 本指南对应**功能级** 12 章节；全套交付物还须满足**文档级 12 项**（元信息 / 背景·可量化目标 / 做·不做范围 / 场景故事 / 流程图与页面跳转 / 逐页面详细需求 / 异常六类 / 数据规则与埋点 / 非功能 / 文案规范 / DoD / 依赖风险待确认），量化标准见 `rules/prd-standard.mdc`。

## 1. 功能标识

- 内容：唯一 ID（如 `F01`）+ 名称。
- 自检：ID 在整套 PRD 内唯一、稳定，后续原型与核验引用同名。

## 2. 背景与目标

- 内容：为什么做、解决什么问题（含痛点数据）、业务价值、成功标准（**可量化**）。
- 自检：成功标准可判定、有量化指标，不含模糊词（黑名单见 `rules/prd-standard.mdc` §二）。

## 3. 使用角色

- 内容：哪些角色使用、权限差异。
- 自检：有权限差异时，必须写清各角色可见/可操作范围。

## 4. 前置条件

- 内容：进入该功能前必须满足的状态/数据/权限。
- 自检：可从"主流程第 1 步之前"验证。

## 5. 主流程

- 内容：正常路径，编号步骤，每步含操作与系统响应。
- 自检：步骤间无逻辑断裂，可从第一步走到最后一步。

## 6. 分支与异常

- 内容：备选路径、失败、边界、超时、并发冲突，按**异常六类**（网络 / 空数据 / 报错 / 权限 / 重复操作 / 超限）逐一写明触发条件、页面表现、逐字文案、数据是否保留。
- 自检：六类中该功能适用的形态全部覆盖，无遗漏；临界值、反向操作、非法输入逐条列出。

## 7. 业务规则

- 内容：校验、状态流转、计算规则、限值；每条按**四段式具象化**：什么条件 → 展示什么 → 触发什么结果 → 报错什么。
- 自检：每条规则四段式完整、可判定（是/否），状态流转用状态表表达。

## 8. 数据项

- 内容：字段名、类型、必填、取值范围、默认值、校验文案。
- 自检：与原型字段一一对应。

## 9. 界面要素

- 内容：页面/区域/操作元素清单、元素交互；每个页面写明页面用途、控件规则、默认值、显隐条件、输入限制。
- 自检：清单可直接作为原型页面拆分依据，且包含逐页面五要素。

## 10. 验收标准（AC）

- 内容：可判定的验收条件，推荐 Given-When-Then；对应文档级 DoD。
- 自检：模糊词命中 0（黑名单：支持、优化、适当、可能、大概、智能、相关、友好、合理、尽快、流畅、良好）；覆盖正常/边界/异常六类/权限。

## 11. 依赖与关联

- 内容：上下游功能、接口、外部系统、数据来源。
- 自检：每条依赖有明确名称；1+ 模式附源码证据。

## 12. 开放问题

- 内容：未确认项，带 owner 与优先级。
- 自检：无 TBD 占位；每条可指派。

## 模式差异速查

| 章节 | 0-1（new） | 1+（evolve） |
|------|-----------|--------------|
| 溯源 | 对话/文档锚点 | 源码 `路径:行号` |
| 置信度 | 不需要 | 推断项保留 `[推断]` 标记 |
| 界面要素 | 从需求推导 | 从源码页面/接口反推 |
