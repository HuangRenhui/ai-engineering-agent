# 四层流程拆解法 + 分支全量抓取 + 闭环校验

## 一、四层流程拆解（每个功能必须按四层拆完，缺一层即不完整）

| 层 | 覆盖内容 |
|----|----------|
| 1. 用户主动操作流程 | 点击、输入、筛选、提交、删除、导出、导入、登录、退出等所有手动操作链路 |
| 2. 页面联动流程 | 字段联动、单选/多选联动、下拉框变更、弹窗触发、显示隐藏联动 |
| 3. 系统自动流程 | 页面加载自动请求、数据自动回填、状态自动变更、表单自动计算 |
| 4. 后台异步流程 | 定时任务、MQ 消息消费、回调通知、超时处理、数据同步、日志生成 |

## 二、分支&异常全量抓取

- 逐行抓取代码中所有 `if/else`、`switch/case`、`try/catch`、拦截器、校验器、状态判断
- **每一个判断 = 一条独立业务流程**，全部纳入流程梳理
- 【强制】禁止合并、禁止简化、禁止"类似地/同上"式省略
- 每条流程记录：触发条件（附代码证据 `文件:行号`）→ 系统行为 → 数据影响（落地/回滚）

## 三、流程闭环校验

每一个功能必须覆盖完整闭环，任一环节缺失即视为该功能梳理不完整：

```
初始化 → 正常操作 → 分支操作 → 异常报错 → 完成/终止 → 数据落地/回滚
```

## 四、逆向纯还原约束（写作时生效）

- 只还原代码**已实现**逻辑：无新增、无优化、无建议
- PRD 中每条逻辑必须对应代码证据（`文件:行号`）
- **不允许概括性描述**：禁止"支持多种查询"式写法，必须逐一列出每一种查询及其触发条件、返回差异
